# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Arbeitssuche, please report it
through [GitHub Security Advisories](https://github.com/xop/arbeitssuche/security/advisories/new).

**Please do not open a public issue for security vulnerabilities.**

## What to Include

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

## Scope

This policy covers the Arbeitssuche application code and its build/release
pipeline. Third-party dependencies are out of scope but will be triaged if
reported.
